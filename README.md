# ARMAN CUT — نسخه آفلاین (PWA)

از این به بعد نیازی به D1، Functions یا هیچ بک‌اندی نیست. تمام اطلاعات مستقیم
روی خود گوشی (`localStorage` مرورگر) ذخیره می‌شه — یعنی می‌تونی مرحله‌ی
binding و D1 که قبلاً انجام می‌دادی رو کامل رها کنی.

## فایل‌ها
- `index.html` — خود وب‌اپ
- `manifest.json` — مشخصات نصب اپ (اسم، آیکون، رنگ)
- `sw.js` — سرویس‌ورکر، برای کارکرد آفلاین
- `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png` — آیکون‌های اپ

## دیپلوی روی Cloudflare Pages
همون کاری که قبلاً بلد بودی: این فایل‌ها رو (همه توی روت ریپو، بدون پوشه) توی
ریپازیتوری آپلود کن و همون پروژه‌ی Cloudflare Pages بهش وصله — این‌بار دیگه
لازم نیست وارد بخش D1 یا Bindings بشی.

## نصب روی گوشی اندروید (به شکل اپ)
1. با **Chrome** آدرس سایت رو باز کن
2. از منوی سه‌نقطه بالا سمت راست، گزینه‌ی **Add to Home screen** یا
   **Install app** رو بزن
3. یه آیکون قیچی طلایی به اسم **ARMAN CUT** روی صفحه اصلی گوشی اضافه می‌شه
4. با زدن روی آیکون، اپ به‌صورت تمام‌صفحه (بدون نوار آدرس مرورگر) باز می‌شه —
   دقیقاً حس یه اپ واقعی

## آفلاین بودن
بعد از اولین بازدید، صفحه‌ی اپ کش می‌شه و بدون اینترنت هم باز می‌شه. تمام
نوبت‌ها هم روی حافظه‌ی خود گوشی ذخیره می‌مونن، حتی اگه گوشی آفلاین باشه یا
سایت در دسترس نباشه.

## نکته مهم
چون اطلاعات فقط روی همون گوشی/مرورگری ذخیره می‌شه که ثبتش کردی، اگه از یه
گوشی یا مرورگر دیگه وارد سایت بشی، نوبت‌ها رو نمی‌بینی. همچنین اگه
کش/داده‌های مرورگر رو پاک کنی یا اپ رو حذف و دوباره نصب کنی، اطلاعات از بین
می‌ره. برای نسخه‌ای که مشتری‌ها هم بتونن از هر جایی وصل بشن (که قبلاً گفته
بودی می‌خوای)، همون راه‌حل دیتابیسی (D1) لازم می‌شه — فعلاً برای استفاده‌ی
شخصی خودت همین کافیه.
