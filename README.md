# راه‌اندازی روی Cloudflare Pages + D1

## فایل‌ها
- `index.html` — خود وب‌اپ
- `functions/api/appointments.js` — دریافت لیست و ثبت نوبت جدید
- `functions/api/appointments/[id].js` — ویرایش و حذف نوبت
- `schema.sql` — ساختار جدول دیتابیس

## مراحل

### ۱. ریپازیتوری
همه‌ی فایل‌ها (شامل پوشه‌ی `functions`) رو با همین ساختار توی یه ریپازیتوری GitHub آپلود کن.

### ۲. ساخت دیتابیس D1
در Cloudflare Dashboard:
1. برو به بخش **Workers & Pages → D1**
2. **Create database** بزن، یه اسم بذار (مثلاً `arman-cut-db`)
3. بعد از ساخته‌شدن، وارد همون دیتابیس شو و برو تب **Console**
4. محتوای فایل `schema.sql` رو کپی کن، توی کنسول پیست کن و اجرا (Execute) کن — این کار جدول نوبت‌ها رو می‌سازه

### ۳. وصل کردن پروژه Pages
1. برو **Workers & Pages** و پروژه‌ی Pages‌ای که از ریپازیتوری ساختی رو باز کن (یا بساز: Create → Pages → Connect to Git)
2. توی **Settings → Functions → D1 database bindings**
3. **Add binding** بزن:
   - Variable name: `DB`
   - D1 database: همون `arman-cut-db`
4. ذخیره کن

### ۴. دیپلوی مجدد
چون binding رو تازه اضافه کردی، باید یه دیپلوی جدید بزنی تا اعمال بشه:
- از تب **Deployments**، آخرین دیپلوی رو **Retry deployment** کن
- یا یه کامیت خالی به ریپو پوش کن

### ۵. تمام
حالا با باز کردن آدرس `yourapp.pages.dev`، هر نوبتی که ثبت/ویرایش/حذف کنی مستقیم توی D1 ذخیره می‌شه و روی هر دستگاهی که باز کنی همون اطلاعات رو می‌بینی.

## نکته
اگه قبل از انجام مرحله‌ی ۲ و ۳ سایت رو باز کنی، بالای صفحه یه پیام «اتصال به سرور برقرار نشد» می‌بینی — طبیعیه، چون هنوز API به دیتابیس وصل نیست.
